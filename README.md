## 🌟 Overview

**Panta Market** is Solana's premier permissionless prediction protocol. Anyone can create markets on real-world events, trade binary YES/NO outcomes with sub-second finality, and earn yield as markets resolve.

For this competition, Panta has partnered with **NectarFi** to bring community distribution, institutional liquidity, and competition rewards:
- **$500 USDG Bounty Pool**: 5 equal winners ($100 USDG each) for top promotional and educational content.
- **$1,000 Leaderboard Pool**: Separate prize pool split among the top 5 trading volume leaders on Panta.
- **Permissionless Market Creation**: Spin up custom markets, define oracle sources, and earn 1% on every trade generated.

## 🛠 Features & Architecture

### 1. NectarFi Trading Competition Board
- Real-time prediction markets on NectarFi TVL milestones, Solana DEX volume, and ecosystem metrics.
- Live probability bars: $P(YES) + P(NO) = 100\%$.
- 1-click outcome selection preloading the Trade Simulator.

### 2. Bonding Curve Position Simulator
- Live slider for investment collateral ($5 to $500 USDC).
- Simulates price impact on the liquidity pool when new capital is allocated.
- Pro-rata winner payout calculator with instant ROI% and net profit projections.

### 3. Permissionless Market Creator Studio
- Interactive studio to configure community prediction markets.
- Set binary questions, categories, resolution sources (DefiLlama, Solana Tracker), and seed liquidity.
- Computes estimated 30-day creator fee yield (1% streaming fee).
- Generates 1-click JSON payloads ready for deployment.

### 4. Viral 6-Tweet Content Suite
- Compliant with all bounty rules: tags `@PantaHQ`, `@Nectar_finance`, and `@SuperteamNG`.
- Includes official `#PantaMarkets` hashtag and quote-tweet link.
- One-click copy buttons and direct tweet intent.

## 🚀 Quickstart & Development

```bash
# Clone the repository
git clone https://github.com/markankamaransheogarat-sys/panta-prediction-market-hub.git
cd panta-prediction-market-hub/app

# Install dependencies with Bun
bun install

# Run local development server
bun run dev

# Build production bundle
bun run build
```
